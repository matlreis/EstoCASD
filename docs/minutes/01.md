# Reunião 01 
## Data: 23/10/2026

### Pautas

- Basta dois perfis de usuário: morador e administrador. O request pode ser 
algo mais simples, como iniciativa, nome, AP, email e data de devolução. O 
acesso é melhor pelo celular. 

- Uso do QR Code para acessar o item.

- Apenas o administrador precisa ter uma conta para facilitar o uso dos 
usuários.

- Na tabela de itens do CASD, basicamente uma das únicas informações 
pertinentes é a quantidade do item. Lista de itens a ser compartilhada 
posteriormente.

- Funcionalidade de devolução apenas aceita se houver confimacao de admin.

- Criação de um "atalho" para empréstimo, em que apenas se "clica em um botão", 
sem precisar ficar cadastrando novamente os dados -> shortcut para algumas 
iniciativas como o CASD Curso e a Atlética.


- Diferenciação entre os itens do CASD e zeladoria: os itens da zeladoria não 
precisam ter sinalização de empréstimo entre os membros. Basta o histórico de 
utilização e a quantidade disponível atual. Para itens que são vendidos, é 
conveniente a exibição do preço unitário do item.  

- Manutenibilidade do código: todo o projeto vai estar documentado.

- A ideia é que a aplicação não tenha nenhum custo para se manter.

- Os empréstimos precisam ter solicitação até sexta-feira, pois não há 
expediente sábado e domingo.

- Implementação de um agendamento de empréstimo para contornar o problema 
anterior.

- Reunião semanais a cada duas semanas, horário fixo sexta à tarde.

- É útil atribuir aos itens da zeladoria o status se está em uso ou não-
