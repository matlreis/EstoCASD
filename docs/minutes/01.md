# Reunião 01 
## Data: 23/10/2026

1. Basta dois perfis de usuário: morador e administrador. O request pode ser 
algo mais simples, como iniciativa, nome, AP, email e data de devolução. O 
acesso é melhor pelo celular. 

2. Uso do QR Code para acessar o item.

3. Apenas o administrador precisa ter uma conta para facilitar o uso dos 
usuários.

4. Na tabela de itens do CASD, basicamente uma das únicas informações 
pertinentes é a quantidade do item. Lista de itens a ser compartilhada 
posteriormente.

5. Funcionalidade de devolução apenas aceita se houver confimacao de admin.

6. Criação de um "atalho" para empréstimo, em que apenas se "clica em um botão", 
sem precisar ficar cadastrando novamente os dados -> shortcut para algumas 
iniciativas como o CASD Curso e a Atlética.


7. Diferenciação entre os itens do CASD e zeladoria: os itens da zeladoria não 
precisam ter sinalização de empréstimo entre os membros. Basta o histórico de 
utilização e a quantidade disponível atual. Para itens que são vendidos, é 
conveniente a exibição do preço unitário do item.  

8. Manutenibilidade do código: todo o projeto vai estar documentado.

9. A ideia é que a aplicação não tenha nenhum custo para se manter.

10. Os empréstimos precisam ter solicitação até sexta-feira, pois não há 
expediente sábado e domingo.

11. Implementação de um agendamento de empréstimo para contornar o problema 
anterior.

12. Reunião semanais a cada duas semanas, horário fixo sexta à tarde.

13. É útil atribuir aos itens da zeladoria o status se está em uso ou não.
